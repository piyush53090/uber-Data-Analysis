# 🚖 Uber Trip Analysis Dashboard | Power BI

An interactive Power BI dashboard developed to analyze Uber trip data and provide actionable business insights through dynamic KPIs, interactive visualizations, and vehicle-level performance analysis.

![Dashboard Preview](Images/overview.png)

---

# 📌 Project Overview

This dashboard transforms raw Uber booking data into meaningful business insights that help monitor operational performance, customer behavior, revenue generation, and trip trends. Users can interact with the dashboard using vehicle and time-based filters to perform detailed analysis.

---

# 🎯 Business Objectives

- Monitor booking performance using key business KPIs.
- Compare revenue across different vehicle categories.
- Analyze completed, cancelled, and incomplete rides.
- Track monthly and quarterly booking trends.
- Identify top pickup and drop locations.
- Evaluate customer and driver ratings.
- Enable interactive filtering for deeper business analysis.

---

# 📊 Dashboard Features

### 📈 Key Performance Indicators

- Total Bookings
- Cancelled Bookings
- Total Revenue
- Total Trip Distance
- Average Trip Distance

### 🚖 Vehicle Analysis

The dashboard allows users to analyze individual vehicle categories such as:

- Auto
- Bike
- Go Mini
- Go Sedan
- Premier Sedan
- XL

For each vehicle type, users can compare:

- Booking volume
- Revenue generated
- Monthly and quarterly trends
- Customer ratings
- Driver ratings
- Trip distance

### 📅 Time Analysis

Switch between **Monthly** and **Quarterly** views to analyze booking and revenue trends over different time periods.

### 📍 Location Insights

Identify:

- Highest pickup location
- Highest drop location

This helps understand demand concentration across different areas.

### ⭐ Service Quality

Monitor customer experience using:

- Customer Rating
- Driver Rating

### 🚫 Ride Status Analysis

Track:

- Completed Rides
- Cancelled Rides
- Incomplete Rides

This provides insights into operational efficiency and ride completion performance.

---

# 💡 Key Business Insights

The dashboard answers important business questions such as:

- Which vehicle category generates the highest revenue?
- Which vehicle type receives the maximum bookings?
- How do bookings change month over month and quarter over quarter?
- Which pickup and drop locations have the highest demand?
- What is the average trip distance across vehicle categories?
- How do customer and driver ratings compare?
- What percentage of rides are cancelled or remain incomplete?
